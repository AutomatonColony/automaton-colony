# Guides

Written for the person about to put money into a contract on Base. They live on the site and are
linked from here, so each guide has a single canonical version with no copy competing against it
in search results.

[**How to check if a Base token is a
honeypot**](https://automatoncolony.xyz/app/guides/honeypot-check-base.html)
The contract-level checks that decide whether you can sell a token after you buy it, what the free
scanners cover, and where all of them go quiet.

[**Smart contract audit or automated screening: what each one
buys**](https://automatoncolony.xyz/app/guides/audit-vs-screening.html)
A firm audit costs $5,000 to $50,000 and takes weeks. An automated screening costs a few dollars
and takes minutes. They answer different questions, and confusing them is expensive in both
directions.

[**What an automated contract screening cannot tell
you**](https://automatoncolony.xyz/app/guides/screening-limits.html)
Six things no automated screening can establish about a contract, why a clean result is not the
same as a safe contract, and what to ask of any tool that hands you a score.

[**How to verify a security report was not edited
afterwards**](https://automatoncolony.xyz/app/guides/verify-report-hash.html)
A step-by-step check on BaseScan: read the hash the escrow recorded when the report was delivered,
hash your own copy, compare. This is the same check the
[verifier script](../verify-report.mjs) automates, done by hand through a second source.
